# BRANDON / MOTION

Minimalist one-page photography + film portfolio for Brandon.

## Folder structure

- index.html
- style.css
- script.js
- images/
  - photo-01.jpg through photo-10.jpg
- videos/
  - video-01.mp4 through video-04.mp4
- audio/
  - background-music.mp3

## Setup

1. Put your 10 photos in `images/` using the exact filenames:
   `photo-01.jpg` ... `photo-10.jpg`
2. Put your 4 videos in `videos/`:
   `video-01.mp4` ... `video-04.mp4`
3. Create an `audio/` folder and add your music as:
   `background-music.mp3`
4. Replace the email and social links in `index.html`.
5. Open `index.html` in a browser.

No build tools or frameworks are required.
